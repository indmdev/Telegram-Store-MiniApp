Una hermosa MiniApp de Tienda de Telegram desarrollada por los equipos InDMDev: la mejor MiniApp de tienda para Telegram que todo vendedor debería tener.

Las Mini Apps de Telegram son aplicaciones basadas en la web que funcionan directamente dentro de la interfaz de Telegram, lo que garantiza una experiencia de usuario fluida y uniforme. Pueden aprovechar una amplia gama de funcionalidades integradas, como autenticación de usuarios sin esfuerzo, procesamiento de pagos integrado y muchas otras características avanzadas.

# 🚀 Características principales:

    # Frontend (Mini App de Telegram)
    Diseño hermoso y responsive con interfaz de usuario/experiencia modernas
    Catálogo de productos con categorías y búsqueda
    Funcionalidad de carrito de compras
    Integración con la App Web de Telegram
    Interfaz optimizada para dispositivos móviles
    
    # Backend (PHP + MySQL)
    Puntos de extremo de API RESTful para productos y pedidos
    Operaciones seguras en la base de datos con PDO
    Sistema de autenticación para administradores
    Sistema de gestión de pedidos
    
    # Panel de administración
    Panel de control con estadísticas
    Gestión de productos
    Seguimiento de pedidos
    Sistema seguro de inicio de sesión

    # Base de datos
    Esquema completo de MySQL
    Datos de muestra de productos
    Optimizado con índices adecuados
    Relaciones seguras entre tablas

    # Métodos de pago
    Criptomonedas
    Personalizado (Acepta cualquier método de pago)
